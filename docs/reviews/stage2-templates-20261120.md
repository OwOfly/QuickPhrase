# 阶段二：变量模板（2026-11-20）

- 基础：`0ea1944`（拼音检索）
- 范围：FR-13 `{date}` / `{time}` / `{datetime}`
- 不变：数据 schema、搜索索引、注入安全边界

## 交付

| 项 | 实现 |
| --- | --- |
| 模板 | `{date}` → `YYYY-MM-DD`，`{time}` → `HH:MM`，`{datetime}` → `YYYY-MM-DD HH:MM`，使用本地时间 |
| 转义 | `{{` → `{`，`}}` → `}`；未知 token 原样保留；未闭合 `{` 原样保留 |
| 预览 | 面板列表的内容预览按当前时间展开模板；模板渲染改变文本时不使用旧高亮区间 |
| 插入 | 面板提交、粘贴模式可用性判断均使用渲染后的文本；复制-only 路径同样获得展开结果 |
| 数据 | 保存原文，不把渲染结果写回；每次预览/插入重新取当前时间 |

## 说明

- 预览与插入各调用一次渲染，跨分钟边界时结果可能相差一分钟。
- 只渲染正文，不渲染标题。
- 模板展开在注入前的现有长度/区域校验之前完成，超长/区域不兼容仍走复制-only 安全路径。

## 残留

- 仅三个固定 token，不支持自定义格式、日期偏移、剪贴板/选区变量。
- 搜索仍匹配原文（含 `{date}` 字面），不索引渲染值。
- 预览不显示“模板”标识；用户只能从内容判断。
- 未在真实 IME/跨应用插入矩阵中验证模板文本。
