# 阶段三：标签云、多标签 AND 与全选筛选结果（2026-11-23）

- 基础：`ddb7539`（标签筛选与批量标签）
- 范围：面板标签云、面板/管理多标签 AND、管理“全选”当前筛选结果
- 不变：注入、快捷键、全局热键、schemaVersion 1

## 交付

| 项 | 实现 |
| --- | --- |
| 标签云 | 面板分类栏下方一行标签芯片，显示名称与计数；点击切换选中；无标签时不占行高 |
| 多标签 AND | 管理搜索 `#a #b`；面板搜索 `#a #b`；标签云可同时选中多个标签，全部条件 AND |
| 查询解析 | `search::split_tag_query` 统一解析前导 `#tag`，返回标签列表 + 剩余关键词；非 `#` 开头保持原搜索 |
| 全选 | 管理搜索行新增“全选”按钮，选择当前筛选结果全部行并进入批量标签模式 |
| 批量 | 复用 `Store::add_tags/remove_tags` 原子写入；批量输入/按钮语义不变 |
| 兼容 | 单选、分类筛选、单标签下拉、普通 `#tag`、快捷键与注入不变 |

## 交互

- 面板标签芯片按计数降序、名称次序排列；只显示当前宽度能容纳的标签，不横向滚动。
- 选中标签芯片显示为主题色；搜索框里的 `#tag` 也会高亮对应芯片。
- 管理搜索 `#support #refund 退款`：标签 AND + 关键词“退款”。
- “全选”在回收站视图同样可用，只批量改标签。

## 残留

- 标签云只显示一行能容纳的标签，无滚动/“更多”；标签很多时后面的不可见，可用管理下拉或搜索。
- 标签云只按全局计数排序，不随分类/关键词动态重算计数。
- 多标签语法只解析查询开头连续的 `#tag`；`关键词 #tag` 不会触发标签过滤。
- 面板 `#tag`/标签芯片不支持含空格的标签。
- 查询框里的 `#tag` 与芯片选中可叠加；芯片不能移除查询中的 `#tag`，需清空/修改搜索框。
- 标签芯片与关键词同时造成空结果时，空态提示只归因标签，可能不精确。
- 批量输入为临时草稿；切换搜索/筛选/视图/关窗不提示丢弃。
- 全选烟测覆盖筛选子集与全量；单行/回收站全选仍靠静态与手工验证。
- 真实鼠标点击标签芯片与 125/150/200% DPI 视觉矩阵待交互桌面验证。
