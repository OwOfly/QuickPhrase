# QuickPhrase UI v2 打磨与复核修复（2026-11-20）

- 基础：c59613e 之后工作区的 Fluent/Direct2D 重做版
- 范围：面板、管理窗口、设置窗口、关于窗口、Direct2D 自绘托盘菜单
- 本轮按只读复核发现顺序修复，未改变注入、存储、热键、托盘与剪贴板语义

## 已修复

| 项 | 处置 |
| --- | --- |
| 设置窗口最小高度下输入页被页脚裁切 | 默认高度 560、最小高度 540；输入页在最小尺寸下完整显示 |
| 设置自绘控件无键盘路径 | 增加焦点模型：Tab/Shift+Tab 在导航、卡片、原生按钮间移动；方向键移动焦点；Space/Enter 激活；自绘焦点环；录制态不拦截 Tab |
| 关于窗口键盘不可用 | 主循环与 about-test 接入 `IsDialogMessage`；显示时聚焦“关闭”；Esc 走 IDCANCEL |
| 管理窗口“置顶”仅鼠标 | 改为原生 owner-draw `BUTTON`（`WS_TABSTOP`），Space/Enter 可切换，保留整卡点击 |
| 深色/危险按钮对比度 | 保留 `primary_active`/`danger` 令牌，浅色 muted 调至 `#646C86`，补 muted 对比度断言 |
| Direct2D 失败无恢复 | `EndDraw`/`BindDC` 失败时丢弃引擎，下一次绘制重建；错误只记录一次 |
| 关于窗口 DPI | 按鼠标所在显示器取 DPI，处理 `WM_DPICHANGED`，重建字体并重排 |
| 外观页 100% 最小宽度 | 主题卡最小宽度 90→80，三卡不侵入右侧留白 |
| 格式化/静态检查 | `cargo fmt --check` PASS；`cargo clippy --release` 0 警告 |
