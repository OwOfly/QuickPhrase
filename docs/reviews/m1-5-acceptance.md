## 已实现

| 项 | 实现 |
| --- | --- |
| 窗口 | `QuickPhrase.SettingsWindow`，560×430，Per-Monitor DPI |
| 热键 | 显示当前组合；「录制」后捕获下一组修饰键 + 键；保存时在主窗口重新注册，失败回滚并提示 |
| 热键解析 | `Ctrl/Alt/Shift/Win` + `A–Z/0–9/F1–F24`，大小写不敏感 |
| Tab 策略 | 当前固定 `spaces4`；「保留制表符」等粘贴模式选项在 M1-7 开放 |
| 主题 | `system` / `light` / `dark` 偏好落盘（深色渲染属 M1-8） |
| 开机启动 | 写/删 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\QuickPhrase` |
| 数据目录 | 只读展示 `%LocalAppData%\QuickPhrase` |
| 剪贴板 | 「恢复上次复制的剪贴板内容」调用内存快照 |
| 持久化 | `storage::save_settings`，写入失败回滚内存 |
| 应用接线 | 启动、暂停恢复、设置保存都从 `settings.hotkey` 注册 |

- `--settings-test` 窗口创建/关闭退出码 0。
- 真实应用打开设置并保存：`settings.json` 中 `theme=dark`、`tabPolicy=spaces4`，热键仍 `Ctrl+Alt+Q`。
- `cargo test` 100/100（新增热键解析 4 个）。

## 复核修复（r1）

| 发现 | 处置 |
| --- | --- |
| Alt 组合录制收不到（`WM_SYSKEYDOWN`） | 录制同时消费 `WM_SYSKEYDOWN` |
| 暂停态保存会重新激活热键 | `apply_hotkey` 在暂停时只更新存储，不注册；恢复时用新组合 |
| 热键回滚错误被吞、提示失真 | 检查旧热键重注册与旧设置回写，任一失败明确提示「回滚失败」 |
| 注入拒绝路径覆盖剪贴板无快照 | 四处改为 `set_text_with_snapshot` |
| 恢复剪贴板会覆盖新内容 | 快照记录剪贴板序列号，序列不符拒绝恢复 |
| Tab「保留制表符」当前无效果 | 只保留「Tab 转 4 空格」，其余选项等 M1-7 |
| 设置项无标签/说明 | 增加全局快捷键 / Tab 键 / 主题 / 数据目录标签 |
| 无最小尺寸、无 `WM_DPICHANGED` | 最小 480×380；处理 DPI 变化 |
| 键盘导航无效 | 接入 `IsDialogMessage` |
| 录制中取消/关窗仍处于录制态 | `load`/显示/关闭统一清除 |
| 非法组合误报「被占用」 | 录制时先用 `parse` 预校验 |
| 注册表句柄在取 exe 失败时泄漏 | 先取 exe 再开键 |
| 开机启动失败仍存 `startup=true` | 失败回滚该字段 |
| 关于文案陈旧 | 改为 M1-5 |

## 已知偏差 / 未覆盖

- 「兼容粘贴」输入方式未暴露，属 M1-7（避免出现不可用选项）。
- 主题仅存偏好，深色渲染属 M1-8。
- 数据目录不可修改，只展示；迁移属 M1-9/后续。
- 剪贴板快照仅本次进程内存，序列变化后拒绝恢复；托盘侧恢复入口属 M1-6。
- Tab 策略当前固定 4 空格；「保留制表符」等粘贴模式选项在 M1-7 开放。
- 热键录制未自动化（需要真实修饰键状态），仅代码路径与解析单测。
- 开机启动在受限环境可能失败，失败时提示「已保存；开机启动未生效」。
