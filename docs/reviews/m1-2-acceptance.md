# M1-2 检索验收记录（2026-11-19）

- 范围：blob 匹配、D16 打分、排序、前 50、命中区间
- 依据：`docs/_ref/final-plan.md` D16、§8 M1-2
- 复核：待独立复核

## 已实现

| 项 | 实现 |
| --- | --- |
| 匹配 | 用 `searchBlob`（小写标题 + `\n` + 小写正文）做子串匹配，零额外分配 |
| 打分 | 标题精确 400 / 前缀 300 / 包含 200 / 正文 100 |
| 排序 | 分数降序 → pinned → lastUsedAt 降序（空值在后）→ updatedAt 降序 → sortOrder 升序 → id 升序 |
| 上限 | 前 50 条 |
| 命中区间 | 标题/正文各返回一个字节区间，供 M1-3 高亮 |
| 空查询 | 返回全部（受 50 上限），按 D16 顺序 |
| 面板 | `filter_items` 改走 `search::rank`，列表顺序与 D16 一致 |

## 实测

```
search bench: n=1000 queries=100 p50=194us p95=217us max=269us
```

- 计时包含每次查询重建 1,000 条的视图（模拟面板每次键入）。
- 目标 ≤50 ms，实际 p95 **0.22 ms**。

## 单元测试（6 个）

- 空查询顺序（pinned 优先）
- 400/300/200/100 打分顺序
- 大小写不敏感 + 标题/正文命中区间
- 同分时 lastUsedAt → updatedAt 决胜
- 前 50 截断
- 1,000 条基准冒烟

## 已知偏差 / 未覆盖

- 多关键词按整串子串匹配，未做分词 AND/OR；拼音在 M2。
- 高亮区间只计算不渲染；渲染属 M1-3。
- `find_range` 依赖“小写化不改变字符数”，CJK/拉丁文成立；特殊大小写映射字符可能偏移一个字符。
- blob 由存储层在加载/保存时重建；外部手改 `data.json` 的标题若不同步 blob，需重启重建后才可检索。
- 基准机为当前开发机，未固定硬件（D17）。

## 结论

D16 的打分、排序与前 50 已实现并通过单测；1,000 条 P95 远低于 50 ms。待独立复核后进入 M1-3。
