# 阶段三：短语标签与检索（2026-11-22）

- 基础：`d121226`（阶段二验收文档）
- 范围：FR-12 标签检索的最小可用切片
- 不变：注入、热键、托盘、数据 schemaVersion

## 交付

| 项 | 实现 |
| --- | --- |
| 数据 | `Snippet.tags: Vec<String>`，`#[serde(default)]`；旧数据自动空标签 |
| 校验 | 最多 10 个、单个 ≤24 UTF-16；trim、大小写不敏感去重；导入用同一套校验（`import_tags`） |
| 编辑 | 管理窗口正文下方“标签（逗号分隔）”输入框；保存/载入/脏状态/错误红框 |
| 检索 | 标签加入 `search_blob`；纯标签命中按 85 分，低于字面 100 和拼音 90；≥2 字符才启用 |
| 兼容 | 标签随 JSON 导出/导入；旧文件无 tags 默认空；不改 schemaVersion |

## 说明

- 标签只做检索，不在面板/管理列表单独展示；标签过滤未做。
- 标签搜索与标题/正文混合匹配；纯标签命中无高亮。
- `search_blob` 仍为内存派生字段，不写入 `data.json`。

## 残留

- 无标签筛选栏/标签云；标签只靠搜索框。
- 不支持批量改标签、层级标签、颜色。
- 标签大小写保留显示，比较时忽略大小写。
- 真实跨应用检索未验证。
