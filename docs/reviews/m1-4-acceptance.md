# M1-4 管理窗口验收记录（2026-11-19）

- 范围：三栏管理窗口、CRUD、分类、回收站、校验、未保存拦截
- 依据：`docs/_ref/prd-v1.1.md` §14.4、`docs/_ref/final-plan.md` §8 M1-4
- 复核：待独立复核

## 已实现

| 项 | 实现 |
| --- | --- |
| 窗口 | `QuickPhrase.ManageWindow`，默认 1040×650，最小 800×540，Per-Monitor DPI |
| 左栏 | 全部 / 各分类 / 回收站；底部「分类名 + 添加」「删除分类」 |
| 中栏 | 搜索框、短语列表、新建、删除、回收站内「恢复」 |
| 右栏 | 标题、正文（多行）、分类下拉、置顶、保存、取消、状态行 |
| 存储 API | `add/update/soft_delete/restore/purge`、`add/delete/rename_category`、`get`、`deleted_snippets` |
| 校验 | 标题 1–80、正文 1–10,000 UTF-16；空值、超长、同名（不区分大小写）、分类不存在 |
| 回收站 | 软删除后进回收站；可恢复；彻底删除前二次确认 |
| 分类 | 新增/删除；删除前确认，短语移到「未分类」 |
| 未保存 | 切换分类/短语、新建、关闭窗口前提示放弃；取消恢复当前内容 |
| 删除确认 | 移入回收站与彻底删除均二次确认 |
| 入口 | 托盘右键「管理短语」与双击托盘图标打开管理窗口 |
| 自测 | `--manage-test` 管理窗口独立启动，关闭窗口即退出 |

## 实测

- `--manage-test` 窗口创建成功、可见、关闭后退出码 0。
- 通过 `WM_SETTEXT` + `BM_CLICK` 驱动真实控件：
  - 保存新短语：snippets 3 → 4，`revision` 7 → 9；
  - 添加分类：categories 2 → 3；
  - 状态行显示「已保存」。
- 二次保存后分类保持：`categoryId` 仍为原分类。
- 最小尺寸（1000×675 @125%）下置顶与保存/取消无重叠。
- `cargo test` 96/96（存储 30）。

## 复核修复（r1）

| 发现 | 处置 |
| --- | --- |
| 模态确认框期间托盘入口触发 RefCell panic | `show`/`shutdown`/`WM_CLOSE`/`WM_DESTROY` 改用 `try_borrow`；模态期操作降级为日志 |
| 保存后分类下拉被清空，二次保存丢失分类 | `reload_categories` 保留原选中项；保存后重载编辑器 |
| 最小窗宽下置顶与保存/取消重叠 | 分类+置顶一行、保存/取消一行；combo 宽度按右栏自适应 |
| 管理列表硬截断 500 条 | 改为不截断 |
| 删除分类/恢复绕过未保存拦截 | 两条路径先检查 `dirty` 并确认 |
| 列表切换拒绝后选中项不回退 | 按旧 `editing` 恢复 `LB_CURSEL` |
| 正文尾部空白被删除 | 只判空，保存原文 |
| 恢复可制造同名活动短语 | 恢复前查重，冲突返回 `duplicate_title` |
| 分类删除失败未回滚 `updated_at` | 回滚时一并还原 |
| 关窗“放弃”未真正丢弃 | 确认后重载持久化内容 |
| 托盘退出不检查未保存 | `manage::confirm_exit()` 前置确认 |
| 初始尺寸未按 DPI 缩放、无 `WM_DPICHANGED` | 创建按系统 DPI 缩放；新增 DPI 变化处理 |
| 最小化时负尺寸布局 | 零客户区直接跳过 |
| Tab/Enter 导航不可用 | 控件加 `WS_TABSTOP`，消息循环加 `IsDialogMessage` |
| `--manage-test` 失败挂起/无互斥 | 取单实例锁，创建失败 exit 4 |
| 类画刷与标题字体未使用/泄漏 | 类画刷纳入释放；标题使用标题字体 |
| 关于对话框版本陈旧 | 改为 M1-4 |

## 复核修复（r2）

| 发现 | 处置 |
| --- | --- |
| 新建未保存时拒绝切换，列表仍高亮新行 | 无可回退项时清空选中（`LB_SETCURSEL -1`） |
| 模态占用时 `confirm_exit` fail-open | 改为拒绝退出并记日志 |
| 状态行与正文底部重叠 | 状态行移到按钮行左侧，正文不再被遮挡 |
| 多行正文 Enter 触发默认保存按钮 | 正文控件加 `ES_WANTRETURN`，Enter 换行 |
| 状态行初始字体与 DPI 变化后不一致 | 创建时同样设置正文字体 |

## 已知偏差 / 未覆盖

- 分类重命名 API 已实现，但暂无 UI 入口（`rename_category` 标 `dead_code`）。
- 导入 / 导出未实现（M1-5/后续）。
- 左栏未显示每个分类的短语数量（PRD 14.4 要求）。
- 校验只在状态行提示，未做字段级红框。
- 未做键盘 Tab 顺序的显式定制，依赖原生控件顺序。
- 未实现回收站 30 天自动清理。
- 管理窗口像素级外观与深色主题属 M1-8。
- 真实鼠标操作未自动化（当前为控件消息驱动）。

## 结论

M1-4 的三栏、CRUD、分类、回收站与校验已接入并通过控件级实测；待独立复核后进入 M1-5 设置。
