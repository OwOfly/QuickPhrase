# 阶段三：短语专属快捷键（2026-11-22）

- 基础：`5c3e305`（阶段三标签检索）
- 范围：FR-15 短语专属快捷键的最小可用切片
- 不变：注入守卫、剪贴板恢复、应用输入例外、暂停语义、schemaVersion 1

## 交付

| 项 | 实现 |
| --- | --- |
| 数据 | `Snippet.hotkey: Option<String>`，`#[serde(default, skip_serializing_if = "Option::is_none")]`；旧数据无字段即无快捷键 |
| 校验 | `hotkey::parse` 解析 Ctrl/Alt/Shift/Win + 字母/数字/F1–F24；保存时规范化为 `Ctrl+Alt+1` 形式；空值清除 |
| 唯一性 | 同一快捷键在所有短语（含回收站）中唯一；与全局唤起快捷键冲突时拒绝保存 |
| 冲突探测 | 保存前用临时注册探测其他程序占用；录制/保存失败在管理窗口红框提示 |
| 注册 | 启动、管理保存/删除/恢复、设置导入/恢复备份、暂停/恢复时重建；ID 单调分配且不复用，避免旧队列消息串到别的短语 |
| 直出 | `WM_HOTKEY` → 捕获目标 → 同一 `inject::run` 守卫/粘贴策略 → 结果托盘气泡；不打开面板 |
| 安全 | 目标为 QuickPhrase 自身时忽略；无目标、身份/区域不确定、`SendInput` 失败均不重试；修饰键未释放（`inject` 守卫 300 ms）只复制 |
| 兼容 | 导入校验 `import_hotkey`（格式、重复、与全局热键冲突）；导出保留；回收站保留，恢复时再次防重复 |

## 交互

- 管理窗口正文与元数据之间一行两列：左“标签”，右“专属快捷键”。
- 专属快捷键为普通单行输入框，留空表示不设置；提示“如 Ctrl+Alt+1”。
- 不提供录制按钮；避免录制期间全局热键截获按键。设置页的全局热键仍用录制。

## 说明

- 快捷键是“直出”路径：按下即捕获并注入，没有面板确认步骤；所有不确定分支仍回落到剪贴板。
- 注册失败（被其他程序抢占）只记日志并跳过该条，不阻断启动；用户可在管理窗口改键。
- 快捷键随暂停一起停用，恢复时重新注册。
- 快捷键在同一条数据内唯一，回收站中的短语仍保留其快捷键；彻底删除后释放。
- 快捷键不参与检索，不写入 `search_blob`。

## 残留

- 无快捷键录制控件，需要手动输入组合；不支持鼠标侧键/媒体键。
- 自动烟测投递 `WM_HOTKEY` 并断言注册日志，未模拟物理组合键；真实按键注册与跨应用矩阵待交互桌面验证。
- 无“快捷键占用总览”或一键跳转冲突项；冲突提示在保存时给出。
- 面板/管理列表不显示快捷键徽标。
- 真实跨应用矩阵（Chrome/Word/VS Code/终端/微信、IME、125/150/200% DPI）仍待交互桌面验证。
- 直出路径的粘贴模式沿用应用例外；未新增独立的快捷输入策略。
- 手动编辑 `data.json` 写入非规范大小写/空格时，保存/恢复的字符串查重可能漏检；应用内保存、导入都会规范化，重复注册失败只跳过该键，不会错注入。
- 主窗口 `WM_CLOSE` 未像托盘退出那样延迟注入；主窗口常态隐藏，无正常触发路径，Task Manager 强退不在保护范围。
