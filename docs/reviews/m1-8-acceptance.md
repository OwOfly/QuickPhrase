## 已实现

| 项 | 实现 |
| --- | --- |
| 主题令牌 | 新增 `src/theme.rs`：PRD §14.2 浅色值 + 对应深色值（页面/卡片/标题/次要/边框/选中/主色/高亮/成功/警告/错误/输入框） |
| 跟随系统 | `theme=system` 读取 `HKCU\...\Themes\Personalize\AppsUseLightTheme`；读取失败按浅色 |
| 对比度 | 主题单测按 WCAG 相对亮度校验：正文/卡片 ≥4.5，次要文字/主色 ≥3.0，高亮文字 ≥4.5 |
| 面板主题 | 画刷、输入框、列表、页脚、分类芯片、高亮、空态、片段文字均取自令牌；重开面板时按当前主题重建画刷 |
| 面板视觉 | 搜索图标（Segoe MDL2 `E721`）、快捷键提示、右栏「设置」入口、页脚「管理短语」入口 |
| 列表项 | 36 px 类型图标、标题/正文左移对齐、单项 64 px（既有）、选中项在键盘焦点时绘制 2 px 主色边框 |
| 管理主题 | 页面/输入框/文字/列表随主题；类背景改为自绘，避免注册类时固化颜色 |
| 管理增强 | 左栏显示 `全部 (n)`、各分类 `(n)`、`回收站 (n)`；校验失败在对应输入框外绘制 2 px 错误色边框，修改后清除 |
| 设置主题 | 页面与输入框随主题；标签与状态文字用次要色 |
| 动效 | 面板显示 100 ms `AnimateWindow(AW_BLEND)`；先取得前台与焦点再淡入，避免淡入期间键入落入原窗口；`SPI_GETCLIENTAREAANIMATION` 关闭时不动画；测试用 `QUICKPHRASE_TEST_NO_ANIMATION=1` 固定关闭 |
| IME | 既有 `ENTER_ARMED` + 组合串检测：IME 组合期间 Enter 不提交，组合结束后的 Enter 才插入 |

## 实测

- 深色：`theme=dark` 打开面板，客户区像素 `(29,31,43)` = `#1D1F2B`；管理窗口 `(20,21,31)` = `#14151F`，与令牌一致。
- 浅色恢复后窗口回到 `#FFFFFF` / `#F5F6FB`。
- 面板仍为 520×420 @100% DPI；Esc/Enter/焦点恢复/提交未回退。
- `cargo test` 112/112（主题 2 个）；clippy 0 警告；panel-smoke 10/10；tray-smoke 19/19。
- 面板基准（50 条代表性数据 + 快捷键提示，不激活）：p95 **21.8 ms**。
- 真实热键路径（动画开启，含 100 ms 淡入、捕获与主题读取）：`panel shown in 120872 us` ≈ **120.9 ms**，低于 150 ms。

## 复核修复（r1）

| 发现 | 处置 |
| --- | --- |
| 焦点边框要求 list 持有焦点，键盘流中永不出现 | 改为「选中且焦点在搜索框或列表」即绘制 2 px 主色边框 |
| 动画在前台获取前阻塞，淡入期间按键落入原窗口 | 先 `force_foreground` + `SetFocus`，再做 100 ms 淡入 |
| DPI 变化删掉 `small` 字体后未给两个链接重设 | DPI 切换同时更新设置/管理入口字体 |
| 删除/恢复后左栏计数不刷新 | 成功路径统一 `reload_left` |
| 分类错误框在分类修正后不清 | `CBN_SELCHANGE` 清除对应错误；`load_editor` 统一清空 |
| 设置窗口输入框/下拉使用 page 画刷 | 增加并返回 `field_brush` |
| 管理窗口创建失败泄漏三把画刷 | 两条失败路径先释放 |
| 搜索带右侧空白与入口背景突兀 | 点击搜索带聚焦输入；设置入口使用搜索带底色 |
| 页脚双重告警过长被裁 | 双重告警改用短文案 |
| 长快捷键提示被硬裁 | 加 `DT_END_ELLIPSIS` |
| 设置入口高度 26 px | 提到 32 px |
| 关于文案、错误框厚度 | 同步 M1-8；错误框偏移按 DPI 缩放 |

## 已知偏差 / 未覆盖

- 桌面锁屏，未截图；PRD 要求的 100/125/150/200% 视觉矩阵未实测，仅保证布局按 DPI 缩放与 `WM_DPICHANGED` 处理。
- 深色对比度用计算值验证，未做真实屏幕测量。
- 中文 IME 组合 Enter 逻辑为既有实现与代码审阅，锁屏下无法实机输入验证。
- 面板动效只做显示淡入，未做隐藏动画。
- 管理窗口导入/导出入口仍未实现（避免不可用入口），按 PRD 不显示。
- 设置窗口主题切换后需重开生效（无实时刷新）。
- 分类栏、列表的空态/错误态颜色随主题，但未做像素级截图核对。
- 浅色次要文字 `#777D92` 对白底约 4.09:1，按 PRD 令牌保留、UI 元素阈值按 3.0 验收；若要达到正文 4.5 需调整令牌。
- 原生按钮/复选框/组合框与列表选中高亮仍由系统绘制（深色下可能偏亮），未自绘。
- 「设置」「管理短语」为鼠标入口，未加入 Tab 顺序；键盘用户可走托盘菜单。
- 分类栏宽度不足时直接截断，未实现横向滚动（已知遗留）。

统一主题、深色、面板视觉元素、键盘焦点、动效与管理窗口计数/校验红框已接入；待独立复核后进入 M1-9 打包。
