# 阶段三：标签筛选与批量标签（2026-11-22）

- 基础：`75a8d4c`（短语专属快捷键）
- 范围：管理窗口标签筛选、面板 `#标签` 检索、管理列表多选批量添加/移除标签
- 不变：注入、快捷键、全局热键、schemaVersion 1

## 交付

| 项 | 实现 |
| --- | --- |
| 存储 | `Store::add_tags` / `remove_tags`：一次原子写入；标签 trim/去重/≤24 字/≤10 个；大小写不敏感增删；失败回滚 tags/updatedAt/blob |
| 管理筛选 | 搜索框下方“全部标签”下拉；按当前视图（活跃/回收站）汇总标签；选中后过滤列表，标题显示 `#tag` |
| 面板筛选 | 搜索框 `#标签` 前缀：`#support` 只看该标签；`#support 退款` 再按关键词检索 |
| 批量编辑 | 列表加 `LBS_EXTENDEDSEL`；Ctrl/Shift 多选后进入“批量标签”模式；标题/正文/分类/置顶/快捷键禁用，只编辑标签；保存按钮变“添加标签”、重置变“移除标签” |
| 批量结果 | 单次写入，状态栏显示“已为 N 个短语添加/移除标签（实际修改 M 项）” |
| 兼容 | 单选编辑行为不变；回收站也允许多选改标签；标签筛选不进入 schema |

## 交互说明

- 管理窗口标签下拉占搜索框下方一行；列表标题显示 `全部短语 · #support` 和过滤后数量。
- 批量模式头部显示“批量标签”和“已选 N 项”徽标；标题/正文显示首个选中短语作为上下文，但不可编辑。
- 批量模式不标记“未保存”；点击“添加/移除标签”立即原子写入并清空选择。
- 面板 `#标签` 不显示标签芯片；纯标签命中无高亮。

## 残留

- 暂不支持多标签 AND（如 `#a #b`）或标签云/标签芯片栏；面板只支持单个 `#标签` 前缀。
- 面板 `#标签` 不支持含空格的标签；此类标签可在管理窗口下拉筛选。
- 暂不支持“全选当前筛选结果”或跨页批量；需 Ctrl/Shift 手动多选。
- 批量只改标签，不改分类/置顶/快捷键/正文。
- 批量模式的标签输入是临时草稿；搜索、标签筛选、视图切换或关窗不提示丢弃，需先点“添加/移除标签”。
- 标签数量在当前会话内增加后，下拉窗口高度在下次重开管理窗口时重算；当前会话可能偏矮但仍可滚动选择。
- 批量模式添加分类时，成功提示会被退出批量后的“新建短语”状态覆盖；数据与批量退出行为正确。
- 键盘进入批量模式且光标停在置顶卡时，hover 高亮可能保留到下一次鼠标移动；常见鼠标选中路径不受影响。
- 标签下拉为单项筛选，不支持同时选多个标签。
- 真实跨应用与 125/150/200% DPI 视觉矩阵仍待交互桌面验证。
