# 阶段二：面板排序增强（2026-11-20）

- 基础：`36b41e6`（阶段一数据闭环）
- 范围：FR-11 最近使用 / 使用次数排序
- 不变：注入、剪贴板、热键、托盘与数据格式

## 交付

| 项 | 实现 |
| --- | --- |
| 排序模式 | `recent`（最近使用）与 `most_used`（最常使用），`Settings.panelSort` 持久化，默认 `recent` |
| 面板行为 | 搜索命中仍以相关度为主；同分时置顶优先，再按最近使用或累计使用次数排序；空查询时排序模式决定顺序 |
| 截断 | 最近模式沿用排名前 50；最常使用先取全部命中、排序后再截断 50 |
| 设置入口 | 外观与主题页新增“面板排序”卡片与原生按钮，可键盘操作；保存后重开面板生效 |
| 数据 | `PanelRow` / 面板项新增 `useCount`，不改变 `data.json` schema |

- 移除正文 `ES_NOHIDESEL`，`WM_CTLCOLOREDIT` 改 `OPAQUE`。

静态复核通过；实际是否消除症状仍需用户交互桌面复测。
