## 已实现

| 项 | 实现 |
| --- | --- |
| 分类栏 | 搜索框下方 46 px；`全部` + 存储分类；点击切换，选中项背景高亮 |
| 分类切换 | 选中分类后列表重置为首项，搜索词保留；点击后焦点回到搜索框 |

| 空态 | 空库「还没有短语」、无匹配「没有匹配的短语」、分类为空「该分类下还没有短语」、加载失败「加载失败，已进入只读」 |

| 可观测 | 显示时记录 `panel data: items/categories/copy_only/notice`；切分类记录 `panel category` |

## 实测

```
panel data: items=3 categories=2 copy_only=false notice=None
panel category: Some("a322dd1e-...")
panel filter: matches=0
```

- 分类点击经 `WM_LBUTTONDOWN` 注入验证：日志确认切换，`GetGUIThreadInfo` 确认焦点回到搜索框。
- 输入无匹配查询后 `IsWindowVisible(list)=False`，空态不再被列表遮挡。
- 面板冒烟 10/10（尺寸仍 520×420，Esc/Enter/提交/焦点恢复不变）。
- `cargo test` 88/88；新增空态优先级、footer 文案、分类+查询高亮、加载失败映射、文本族格式测试。
- 面板冒烟接受正常提交与仅复制提交两种日志（前台不可输入时走仅复制）。

## 复核修复（r1）

| 发现 | 处置 |
| --- | --- |
| 点击分类后键盘焦点丢失 | `WM_LBUTTONDOWN` 末尾无条件 `SetFocus(edit)` |
| 命中区与绘制区字体不一致 | 命中测量同样选入正文字体并恢复 |
| 空态被 LISTBOX 覆盖 | 结果为空时 `ShowWindow(list, SW_HIDE)`，非空恢复 |
| 高亮三段 2 px 重叠、前缀无省略号 | 后缀起点对齐高亮底右缘；前缀补 `DT_END_ELLIPSIS` |
| 分类按名称排序 | 改按 `sortOrder → name → id` |
| 只读 notice 显示机器码 | 映射为中文短语，未知 token 原样显示 |
| 仅复制缺剪贴板快照 | 写入前保存上一份纯文本，提示覆盖与非文本不可恢复 |
| 能力失败仍显示「Enter 输入」 | 捕获结果不可输入时进入仅复制态，提交不再走注入 |
| 空态/文案无测试 | 抽出纯函数并补优先级与文案映射测试；补分类+查询高亮 |
| 数据目录不可用仍显示「还没有短语」 | `data_load_failed` 纳入 `data_dir_unavailable` / `initial_save_failed` |
| 非文本误判：`CF_TEXT/CF_OEMTEXT/CF_LOCALE` 是系统合成格式 | 视为文本族，仅真正非文本格式才提示不可恢复；补单测 |
| `rejected` 尝试会改 `updatedAt`，影响 D16 排序 | 仅 `accepted` 更新 `updatedAt`，补断言 |

## 已知偏差 / 未覆盖

- 分类过多时按宽度裁剪，未实现横向滚动（PRD 允许滚动；当前分类数少）。
- 分类栏无键盘访问与 hover 态；类型图标、搜索图标、快捷键提示未做，统一归 M1-8 UI Spec。
- 「管理短语」入口留到 M1-4；「设置」入口留到 M1-5，避免出现不可用入口。
- 空态/高亮的像素级外观未截图核验（本会话桌面锁屏）。
- 仅复制路径未做真实捕获失败 E2E；快照读取与覆盖提示已接，恢复入口属 M1-5。
- 深色主题与面板动画（100–140 ms）属 M1-8。

## 结论

M1-3 的分类、空态、只读态、仅复制态与高亮已接入；r1 三家发现已修（焦点、命中字体、空态可见性、剪贴板快照、能力失败分流）。待 r2 复核后进入 M1-4 管理窗口。
