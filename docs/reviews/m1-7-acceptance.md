## 已实现

| 项 | 实现 |
| --- | --- |
| 输入方式 | `settings.insertionMode`：`unicode`（默认）/ `paste`；设置窗口下拉切换 |
| 粘贴警示 | 选择粘贴模式时弹确认框，写明会替换剪贴板、非文本不可恢复、终端/未知区域/多行仍只复制；拒绝则回退 Unicode |
| 粘贴路径 | 校验通过后写入剪贴板（含上一份快照）→ `SendInput` 发送 Ctrl+V（4 个事件，单次，不重试） |
| 适用边界 | 仅 `identity=verified`、`capability=text`、非提权、完整性已知、区域 `text_editor`、单行、≤10,000 UTF-16 单元 |
| 区域策略 | 终端/未知区域拒绝粘贴（`paste_region`），多行拒绝（`paste_multiline`），不回退到 Unicode |
| 长文本 | Unicode 仍限 2,000 单元；粘贴模式允许到 10,000（内容上限） |
| 序列保护 | 粘贴后记录剪贴板序列变化；从不自动恢复或覆盖外部新内容 |
| Tab | Unicode 固定转 4 空格；粘贴模式可选择保留制表符（`tabPolicy=tab`） |
| 区域标记 | 沿用内置判定（终端 exe/类、Edit/RichEdit/_WwG）；UIA hint 仅作升级，粘贴模式不接受非 `text_editor` |
| UIA 降级 | 连续 2 次超时标记本会话不可用，本次只能复制；阈值抽成纯函数并有单测 |
| 面板提示 | 粘贴模式下页脚显示「Enter 粘贴（Ctrl+V）」；仅复制/只读态仍优先显示复制 |

## 实测

- 设置窗口：`输入方式` 下拉 2 项；选择粘贴并保存后 `settings.json` 为 `insertionMode=paste`。
- 再次打开设置：粘贴模式已选中，Tab 下拉出现 2 项；选择「保留制表符」保存后 `tabPolicy=tab`。
- 恢复 `insertionMode=unicode` 后，Tab 下拉回到单项、保存强制 `spaces4`。
- 锁屏环境下以 document 目标打开面板时，捕获判定不可输入，页脚显示「仅复制（目标不可输入（document））」——粘贴模式未绕过能力判定。
- `cargo test` 109/109（粘贴策略 5 个、页脚 1 个、UIA 降级 1 个、设置持久化与旧文件兼容 2 个）。

## 复核修复（r1）

| 发现 | 处置 |
| --- | --- |
| 剪贴板先 `EmptyClipboard` 再分配，分配失败会丢原内容 | 先分配并填充 `HGLOBAL`，再打开/清空剪贴板；写失败时尝试写回原纯文本 |
| 序列号在关闭剪贴板后读取，可能与外部写入错绑 | 在持有剪贴板期间记录本次写入序列；`restore` 也在同一锁内复核序列再替换 |
| 部分 `SendInput` 接受会残留 Ctrl/V 按下 | 部分接受时补发仅 key-up 的 V↑/Ctrl↑ 清理（非粘贴重试） |
| 复制内容前未复查前台/剪贴板 | Ctrl+V 前复查前台与序列；剪贴板已被替换则中止，不粘贴错误内容 |
| 页脚只看配置，区域不支持或多行时仍说粘贴 | 粘贴模式下区域不支持 → 整体仅复制；选中项不可粘贴（多行/控制字符/超长）→「Enter 复制（不可粘贴）」 |
| 警示框在 UI 可变借用内弹模态，托盘退出/再开设置会 panic | 先释放借用再弹框；`show/shutdown/WM_DESTROY/WM_KEYDOWN` 全部 `try_borrow`，模态期降级并记日志 |
| 拒绝警示后 UI 与已持久化模式可能相反 | 拒绝时回到磁盘上的实际模式，状态文案按实际结果 |
| 旧 `settings.json` 缺 `insertionMode` 会导致整库只读 | 字段级 `serde(default)` 回退 `unicode`，补旧文件加载测试 |
| 只复制气泡缺「可恢复」提示 | `Outcome` 携带 `restorable`，气泡按快照状态提示托盘恢复或不可恢复 |
| 剪贴板读取失败被当成「无文本」 | 快照增加 `read_ok`，只复制提示区分「无法确认原内容」 |
| 关于文案、过期注释、空 `if` 块 | 同步为 M1-7，清理 |

## 已知偏差 / 未覆盖

- 真实编辑器中的 Ctrl+V 端到端未实测（桌面锁屏；需要可交互前台）。
- 锁屏环境下第二实例打开的面板可能因失焦立即隐藏；托盘冒烟改为轮询捕捉可见状态，非交互桌面下不保证稳定驻留。
- 警示框接受/拒绝流程未自动化；已用「警示框打开时托盘再次打开设置 / 托盘退出」手工回归，进程退出码 0 且无 panic。
- 部分发送的 key-up 清理本身无桌面自动化。
- 粘贴模式不检测目标应用是否真的处理 Ctrl+V；结果按 `accepted` 记录，失败由用户观察。
- 各应用兼容性矩阵（Chrome/Word/VS Code/WeChat/终端）仍待解锁桌面后人工执行。
- 区域标记为内置静态列表，未做用户可维护标记包（D21 允许 V1 仅内置）。
- 按应用输入模式（FR-14）与规则求值未实现，属 M2。

粘贴兼容模式、长文本、序列保护与 UIA 降级已接入并通过单测与设置持久化实测；待独立复核后进入 M1-8。
